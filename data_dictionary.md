
# Mutual Fund Analytics — Data Dictionary

## Project Overview

This project analyzes mutual fund assets under management (AUM),
NAV history, scheme performance, investor transactions, and SIP trends
using cleaned CSV datasets, SQLite, and SQL.

- Database: bluestock_mf.db
- Database schema: sql/schema.sql
- Cleaned data folder: data/processed/

## 1. dim_date

| Column | Data Type | Definition | Source |
|---|---|---|---|
| date_key | INTEGER | Unique date identifier | Generated by SQLite |
| full_date | TEXT | Calendar date in YYYY-MM-DD format | Source dates |
| year | INTEGER | Calendar year | Derived from full_date |
| month | INTEGER | Calendar month (1–12) | Derived from full_date |
| day | INTEGER | Day of the month | Derived from full_date |

## 8. Table Relationships

- dim_fund.fund_key → fact_nav.fund_key
- dim_date.date_key → fact_nav.date_key
- dim_fund.fund_key → fact_performance.fund_key
- dim_fund.fund_key → fact_transactions.fund_key
- dim_date.date_key → fact_transactions.date_key
- dim_date.date_key → fact_aum.date_key

## 9. Notes

- Data types describe the SQLite schema.
- Percentage values are stored as supplied by the source datasets.
- Missing values may indicate unavailable information.
- monthly_sip_inflows is an additional table loaded from its cleaned CSV.
- Other processed CSVs are documented above but are not necessarily
  loaded into the six core tables.
